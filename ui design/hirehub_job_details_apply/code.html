About The Role

At Acme Technologies, we build resilient next-generation cloud infrastructure and scalable enterprise logistics systems powering high-volume supply chains across South Asia and Europe. Our digital forwarding platform processes hundreds of thousands of concurrent shipment events every minute, demanding interfaces that are responsive, robust, and intuitive.

As a Senior Frontend Engineer in our Logistics Core team, you will shape the architecture of our business-critical operations command center. You will collaborate directly with cross-functional product teams, champion high-leverage UI design systems, and resolve nuanced technical challenges spanning state orchestration, high-frequency tabular feeds, and internationalized workflows.

Responsibilities

  • check_circle Architect, deploy, and optimize modern responsive web applications using React, TypeScript, and clean CSS architectures.
  • check_circle Collaborate closely with product managers and UX designers to transform product specs into accessible, production-ready interfaces.
  • check_circle Establish frontend benchmarking, design token consistency, component libraries, and automated end-to-end testing pipelines.
  • check_circle Mentor junior team members through thoughtful code reviews, pair programming, and architectural design documentation.

Requirements

task_alt 4+ years of professional software engineering experience in modern JavaScript/TypeScript client ecosystems.

task_alt Experience with modern utility-first CSS frameworks (Tailwind CSS), semantic HTML5, and web accessibility standards (WCAG 2.1 AA).
task_alt Familiarity with Git branching workflows, semantic versioning, and CI/CD pipelines utilizing GitHub Actions.
